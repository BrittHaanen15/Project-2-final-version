# Project 2 FYS3150/4150: Working with eigenvector-eigenvalue problems and the Jacobi rotation algorithm

This repository contains the code for Project 2 in the course FYS3150/FYS4150 at the University of Oslo. 
The project is developed by: Britt Haanen

In this project we set up the Jacobi algorithm for finding the eigenvalues and eigenvectors of matrices. We solved both a specialised tridiagonal case and a dense matrix. The initial correctness of the algorithm was benchmarked against analytical solutions and the Eigen module.
The computations are implemented in C++. Simple unit testing of the C++ code was visualised in the terminal, and we included screenshots of the results (see file tree below). Finally, plotting results are visualised in a Jupyter notebook using Python 3.12.4 and the modules Numpy, pandas, and Matplotlib.

All .cpp and .exe files relevant to this project are contained in the main folder.
- `Project2_outputs/` contains data outputs from the C++ files for plotting
- `include/` contains header files
- `src/` contains source files 
- `plotting/` contains the Jupyter notebook for plotting and the resulting plots as pngs. 
- `screenshots/` contains the output data generated by the C++ scripts for unit testing
- `figures/` contains the figures generated by the python script


## Requirements 
The C++ code requires a compiler supporting C++20. 

The Jupyter notebook requires requires a Python 3 kernel and the packages NumPy, pandas, and Matplotlib.


## Building and running the code 
To build a code run the command

```
g++ -Wall FILE_TO_BUILD.cpp src/*.cpp -I include -o FILE_TO_BUILD.exe
```

To run the program, do

```
./FILE_TO_BUILD.EXE 
```

The generated data is printed to terminal or stored in the `Project2_outputs/` directory. 

## Plotting
Generate the interactively by opening the Jupyter notebook and runnning the code cells.

The corresponding files are automatically stored in the `plotting/` directory.
